## Leitura do projeto

Projeto acadêmico em equipe, com interface desktop Java Swing. `src/br/com/fiap/view/HomeFrame.java` contém uma entrada `main` e abre a tela inicial; seus botões navegam para telas de entrada e cotação. A presença dessas telas não comprova contratação real de seguros ou integração comercial.

A configuração Eclipse está em `.project` e `.classpath`, com fontes em `src` e saída em `bin`. O classpath referencia bibliotecas c3p0, mchange e driver Oracle. Não há configuração Maven/Gradle no projeto.

Para preparar o ambiente de desenvolvimento, confira JDK, bibliotecas, recursos visuais e dependências de banco. A configuração Eclipse não fixa uma versão de JDK.
